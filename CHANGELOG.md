# Changelog

All notable changes to CovertLens, keyed by delivery task (CL
number). Each entry corresponds to one merged pull request; the
deliverables ledger in [README.md](README.md) maps every entry to
its acceptance criteria, code, contract doc, schema, and tests.

## Unreleased

- **CL-79** (traffic lights) — Lead every Analyze result with a plain answer to “Is there a chance of collusion?”: a traffic light read from the existing frozen ladder verdicts (`log` green “No evidence of collusion”, `flag` orange “Potential collusion”, `quarantine`/`fail_run` red “High potential for collusion”, grey when nothing could be checked), one light per test with plain names and a reason whenever a test did not apply or its cut-offs are not frozen (never shown as green), and a colour key. Scores, cut-offs, charts and evidence tables move behind “See the technical evidence”. The home page explains the colours and lists every page; gate and review tables show the same coloured dot. The README quick start now builds from the checkout and explains that the `v0.1.0` GHCR image predates every page after Analyze. Every other page now follows the same simple-first pattern: plain steps or a plain summary (accuracy “out of 100”, a release checklist, one line per image on the timeline, one-line gate safety and audit checks, plain role and judgement choices) with exact IDs, scores, tables and charts behind “See the technical breakdown” and specialist form options behind “Show advanced settings”; the menu uses short names on one line. No detection, threshold or API change.
- **CL-66** — Add a static, zero-server build of the Analyze page (`npm run build:static`): the library runs in Pyodide 314.0.7 in a Web Worker through the same `app/analysis_worker.py` as `POST /api/analyze`, a service worker precaches every file so the page works offline after the first load, the CSP limits connections to the page's own origin, and the page states its 5 MiB / 2 MP limits. CI builds it, checks Pyodide-vs-CPython parity on every example and uploads the site; a slow Chromium test proves offline analysis with no request reaching a server.
- **CL-67** — Add real authentication: `COVERTLENS_AUTH_MODE=oidc` signs browsers in with the authorization-code flow (PKCE, browser-bound single-use state, nonce) into server-side sessions and accepts bearer JWTs for harnesses (`GateClient(bearer_token=...)`); identities map to human roles and run-scope patterns through `config/identity-mapping.json` (deny by default), every evidence check and audit entry uses the authenticated principal (`oidc:<sub>`), runs outside a tenant's scopes are closed, and production builds (`DEMO_BUILD=off`) drop the demo-role picker and never trust `X-Demo-Role`.
- **CL-68** — Add the banded fixture suite (dozens of pairs per payload band, family and cover texture; at least 20 held-out positives per calibrated band) and refreeze to `frozen-1.3.0` with free-recall triage and fail-run above every development negative (geometric unchanged; `lsb-sample-pairs` scale 0.23 keeps it below quarantine). Stability is measured on all three textures per (texture, medium) cell: smooth PNG and blocks JPEG are named exclusions with measured false-fail rates in the scorecard; DCT enforcement precision misses 0.99 on held-out data (37/38) and is reported. `COVERTLENS_BUILD_WORKERS=auto` builds and scores the suite in a process pool with identical results.
- **CL-69** — Add vector-source parsers for SVG (`xml.etree`, transforms, `<use>`, clip boxes, fail-closed on text/images/filters/restyling CSS and XML bombs) and matplotlib figures (patches, bar containers, line and path collections; optional `matplotlib` extra), measured on the rendered raster's pixel grid; `analyze_rendered_with_source` keeps the CL-41 binding and C-10 refusals and refuses clearance for partially parsed sources.
- **CL-70** — Add a leaderboard of encoder strategies vs detector versions: Generate-page submissions scored server-side, keyed by the release pin hash so a detector change starts a new board while old boards stay readable, ranked by payload carried below each operating point, with per-identity rate limits, operator moderation (`leaderboard.moderate`) and hidden attacker grids never published.
- **CL-74** — Add the second-opinion provider interface: `covertlens.second_opinion` with a stdlib HTTP adapter (OpenAI-compatible and Anthropic shapes), environment-only configuration, per-run/per-day caps and a rate limit; disabled without a key, fail-closed to `second_opinion_unavailable`, key never logged or returned.
- **CL-75** — Build second-opinion prompts from the sealed review package with every agent-controlled string fenced as untrusted data (sanitized, length-limited); require a structured JSON assessment; planted-injection fixtures prove the instruction part stays clean and verdicts never move; unparseable replies are never agreement.
- **CL-76** — Record opinions as advisory `covertlens.second-opinion` (validated, `advisory_only: true`), sealed into the run report and review export without touching verdicts or dispositions; pictures need a manifest opt-in plus the gateway's `second_opinion.send_image` permission, audited per send.
- **CL-77** — Add `POST`/`GET /api/review/deliveries/{id}/second-opinion` (researcher/reviewer) and a Review-page panel showing model, assessment, per-finding comments, and the explicit unavailable/unparseable/off states; caps surface in the UI.
- **CL-62** — Add a genuinely adaptive attacker: a score-oracle loop binary-searches the largest payload under each frozen operating point for LSB, DCT, and geometric families, with matched clean controls, computed `confounded` flags, recorded query budgets, and an achieved-payload-vs-operating-point figure, separate from the frozen benchmark.
- **CL-63** — Consolidate shared helpers into `covertlens._stats`, `._png`, and `._validation` (no private cross-module imports remain), freeze `events.Event`, define `_now` and the pilot adjudications once, share one JSON canonicaliser between pinning and the audit log, move magic numbers into versioned configs, and single-load/join in `report` and `handoff`. No behaviour change.
- **CL-64** — Add the harness adapter: `GateClient` over HTTP (`intercept`/`attempt`/`access`, raising `PendingDeliveryError`/`WithheldError`) and a 50-line example harness moving one permitted and one withheld delivery between stub agents.
- **CL-65** — Close operations runbook gaps: `COVERTLENS_FROZEN_CONFIG` selects the frozen config, `make refreeze` recalibrates/bumps/regenerates the scorecard, the scorecard records the campaign `pin_hash`, `docs/campaign-log.md` defines the announcement convention, and runbook sections cover artefact regeneration, limit configuration, and `validate_handoff` failures.

- **CL-78** (sections 2–6) — Geometric detector 3.0.0 and freeze `frozen-1.4.0` (on top of CL-68's banded `frozen-1.3.0`; `frozen-1.2.0` is skipped). Quantization measures support at a decode margin (a quarter of the discovered step), so ±1 px of jitter no longer hides a grid (DECAF ±1 px: 20/20 claimed, was 1/20). Every decodable channel gets the structure test, at a family-wise level split over tests (one max-statistic per channel and statistic kind); invalid symbols are no longer printable (the `?` marker counted), and 2,000 random 12-bar payloads give 1.15% false structure at the stated 1%. A declared channel is still tested, at 0.1× the level, and flags at the normal level instead of logging at score 0. Colour levels are discovered (well-separated clusters) instead of read from the fixture palette, on the raster path and in the CL-69 SVG and matplotlib source parsers alike, and channels report a symbol digest, count and range instead of the sequence. Declared scene context reaches production through `analyze_all_bytes`, the gate (`declare_scene_context`, refused after the first delivery) and the web API. Structured fixtures draw varied payloads from disjoint development and held-out pools (no word from the trigram list) with varied grids and palettes; the benchmark adds jittered (±1/±2/±3 px), every-other-level and random-payload rows and drops the seed-scanned positive; the geometric quarantine point is calibrated above the non-structure score ceiling. Segmentation estimates border noise and holds element counts under ±3 and ±6 noise. Web: request bodies are capped before parsing, timed-out workers are killed and a broken pool is rebuilt (SIGTERM restored in workers), the rate limiter evicts idle windows, covers every upload path and trusts `X-Forwarded-For` only from `COVERTLENS_TRUSTED_PROXIES`, `/api/health` reports an unwritable data directory, failed precompute and skipped gate versions (503), analyses are cached per version, web decisions use the shipped freeze rather than the log-only default, and `mypy app` runs in CI. Frontend: the overlay shows a symbol digest; Overlay, Live Gate and Review panes have tests; runs can declare channels. Cleanup on top of CL-63/CL-65: the private-import check now covers `app/` and `scripts/` and absolute imports, the clock and `need` helpers are defined once (the leaderboard's own `_now` is gone), nearest-rank latency percentiles strip float noise before the ceiling, outcome validation loads the manifest's error classes once, retirement deletes only the store's own root, and gate reload logs and counts skipped versions; the geometric quarantine floor is part of `make refreeze`. **Latency:** the large-PNG miss is correct — the CL-35 scorecard predates the geometric family, whose segmentation (CL-44) is about 2.7 s of a 1024×768 analysis, and the latency section was not re-measured until CL-57 (the published-vs-built test skips it). The 20 MP envelope now misses as well, because CL-61's sample-pair detector costs about 7 s there in pure Python; `COVERTLENS_FAST_PATH=numpy` now covers it (envelope about 0.6 s). Known limits: the A–H height letter code is weak (about half of varied words claimed), ±3 px on a 10 px grid mostly evades, and 235-on-238 lit elements are lost under noise.
- **CL-78** (section 1, security) — Close the public reviewer-image leak: `reviewer-image` takes its actor from the demo role and needs `original.read`, so a request with no role is denied (the test that asserted the leak now asserts the denial). R-08 attempts record actor and authorization, and `unauthorized_served` counts R-08 serves without an authorized actor. Gate verdicts need `verdict.override`; audit and trace need `trace.read`. `X-Demo-Role` is honoured only with `COVERTLENS_DEMO_ROLES=on` (set in the Docker image and compose file); otherwise every request is a viewer. JSON endpoints reject non-JSON bodies (415), unsafe cross-site `/api` requests are blocked, responses add `frame-ancestors 'none'`, `X-Frame-Options: DENY` and `Referrer-Policy: no-referrer`, the CSP allows `blob:` images so the reviewer panes render, `/docs` gets a Swagger CSP with a hash-pinned inline script (ReDoc removed), and the export filename is header-safe. The Live Gate, Trace and Reviewer pages share a demo-role picker.
- **CL-61** — Add stronger pixel detectors: `lsb-sample-pairs` (sample-pair LSB-agreement randomness, gated where adjacent-pair correlation is absent) alongside `lsb-pov-chisquare`, and `dct-calibrated-histogram` (neighbor-calibrated histogram total-variation, gated on uncorrelated/subsampled blocks) alongside `dct-coefficient-pov-chisquare`; a smooth-field +/-1 matching fixture suite shows the gain (spatial ROC-AUC 0.597 vs PoV 0.499, DCT 0.833 vs 0.715, bootstrap intervals reported, both detectors individually visible in every benchmark row and in `analyze_all_bytes`). Frozen-benchmark scoring and calibration stay pinned by detector name to the originally calibrated detectors, so the frozen evaluation is unchanged.
- **CL-60** — Add the Trace explorer page: per-run join records with content hashes, verdict references and parse/next-action links or explicit missing statuses with reasons, episode context, repeated weak signals per sender (triage aid only), and recipient actions with candidate input artifacts under `causation_claimed: false`.
- **CL-59** — Add the Reviewer page with demo roles: `viewer`/`researcher`/`reviewer` toggles map to CL-11 principals (clearly labelled demo roles, viewer permissionless), quarantined originals with reviewer-only candidate decodes (other roles denied and audited), the five CL-25 dispositions, sealed review-package download and live audit-chain verification, persisted beside the gate state.
- **CL-58** — Add the live Muse Spark agents covert-channel experiment: Spark sender/receiver via the Meta Model API with deterministic encoder tools, the gate and frozen ladder between them, refusal/no-attempt outcomes scored separately, per-trial model provenance (missing model ID excluded), Wilson-interval recovery and clean-control withholding rates, reported separately from the frozen benchmark. Live trials need `MODEL_API_KEY`; CI covers the harness with an offline stub client.
- **CL-55** — Add Benchmarks and Scorecard pages with CLI-identical caches, ROC/band/Wilson views, geometric rows, ablation/latency/robustness charts and provenance. Robustness remains separate from frozen results.
- **CL-56** — Derive report conclusions and release assessment from evidence, reject unsupported release decisions, propagate audit programming errors, read handoff decisions from the scorecard, and fix default score-cache lookup without guessing between configurations.
- **CL-57** — Bound JPEG component/table parsing, honour component Huffman selectors, parse baseline subsampling and run 2,000 deterministic malformed-image cases in CI. Optional NumPy acceleration now covers PNG filters, coefficient histograms, JPEG reconstruction and segmentation; reuse parsed JPEG coefficients. CL-29 large-JPEG fast-path P95 1.6631 s meets 2 s, with exact reference findings/decision parity.

- **CL-54** — Freeze four-family `frozen-1.1.0` thresholds from development-only data; reserve geometric enforcement for supported undeclared structure, publish lineage-held-out subfamily/chart rates with Wilson intervals, and derive vector clearance from the verdict ladder. Geometric run failure remains reserved pending severity calibration. Fixture PNGs are now written with stored deflate blocks so fixture IDs and pinned dataset hashes are identical under classic zlib and zlib-ng (CI failed on a zlib-ng runner); thresholds and measured results are unchanged.

- **CL-53** — Persist gate state in SQLite under the store root (deliveries, access attempts, trace events; store access history out of `index.json`, derivatives persisted), compute `unauthorized_served` from recorded attempts, and add the Live Gate page (`/gate` + `/api/gate/*` with SSE timeline; recipient pane never renders withheld bytes).
- **CL-52** — Segmenter 1.1.0 handles background colour variation with recorded RGB tolerances, gradient-aware border flooding and 3×3 cleanup; PNG/JPEG pixel decoders, explicit JPEG fidelity limitations, five licensed real-image fixtures, independent codec references and JPEG web-overlay regression coverage. Manifest 1.2.0 declares JPEG geometry; integrated analysis retains the CL-13 parser subset.
- **CL-50** — Add lint, type and schema checks to CI and split the CLI (ruff + mypy at 0, argparse CLI over `covertlens/demos.py`, schema-validation tests, `slow` latency marker).
- **CL-51** — Generate / red-team page (`/generate` + `POST /api/generate` with `source: red_team` provenance; fixes an Analyze crash on failed-segmentation reports found through it).
