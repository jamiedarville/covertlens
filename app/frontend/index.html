CovertLens

CovertLens scores eval-generated images across four channel families — spatial LSB, JPEG DCT, metadata, and geometric — and records verdicts that are evidence, never accusations.

The interactive Analyze page arrives with the React build (CL-48). The API is live now:

  • /docs — OpenAPI
  • GET /api/health, GET /api/version
  • POST /api/analyze — multipart image upload
  • GET /api/fixtures, GET /api/benchmarks/geometric, GET /api/scorecard
